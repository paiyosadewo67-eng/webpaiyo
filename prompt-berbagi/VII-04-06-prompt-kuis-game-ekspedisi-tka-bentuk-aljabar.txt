📚 Rangkuman Materi Bentuk Aljabar
1. Operasi Bentuk Aljabar
• Suku sejenis dapat dijumlahkan/dikurangkan
• Distributif: a(b + c) = ab + ac
2. Pemfaktoran
• Faktor persekutuan: ab + ac = a(b + c)
• Selisih kuadrat: a² - b² = (a+b)(a-b)
3. Persamaan Linear
• Kumpulkan variabel di satu sisi
• Kumpulkan konstanta di sisi lain
4. Aplikasi Geometri
• Luas persegi panjang = p × l
• Keliling = 2(p + l)
• Luas trapesium = ½(a + b) × t
