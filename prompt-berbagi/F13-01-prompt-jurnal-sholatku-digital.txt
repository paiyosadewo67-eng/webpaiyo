Kelengkapan fitur-fitur yang di harapkan :
Tombol "Hapus Kelas" Berfungsi Lancar (In-App Dialog)
Tombol Hapus Kelas kini menggunakan dialog konfirmasi internal yang responsif dan aman (tidak lagi diblokir oleh browser di HP).
Menghapus kelas akan otomatis membersihkan seluruh data siswa dan catatan sholat di kelas tersebut secara tuntas.
Database Ringan (Contoh 3 Kelas: 9A, 9B, 7A)
Secara bawaan, aplikasi kini disiapkan dengan format ringan 3 Kelas Contoh (9A, 9B, 7A) dengan masing-masing 32 siswa.
Bapak dapat dengan sangat leluasa menghapus kelas yang tidak dibutuhkan atau mengganti namanya.
Kemudahan Input dari File Excel / Daftar Nilai Bapak
Pada tab "Input 32 Siswa Sekaligus", Bapak cukup menyalin (Copy) kolom nama murid dari file Excel daftar nilai, lalu menempelkannya (Paste) ke dalam kotak input.
Tersedia opsi centang "Ganti (Replace) seluruh murid di kelas target" agar daftar nama langsung terisi rapi sesuai urutan nomor absen (1 s/d 32).
Opsi Database Rombel &amp; Reset
Pada menu "⚙️ Opsi Database Rombel", tersedia 3 pilihan fleksibel:
⭐ Muat Contoh 3 Kelas (9A, 9B, 7A) — Sangat ringan untuk mulai diedit sendiri.
🏫 Muat 13 Rombel Lengkap SMPN 1 Bantarkawung (416 Siswa) — Jika sewaktu-waktu membutuhkan database komplit.
🧹 Kosongkan Semua Data Murid — Untuk membersihkan semua kelas dan mengisi dari awal.
Database Server Terpusat &amp; Sinkronisasi Otomatis
Aplikasi kini dilengkapi backend server yang menyimpan seluruh data rombel, nama siswa, dan catatan sholat secara permanen di server.
Setiap kali Bapak menambah/mengedit/menghapus kelas atau nama murid, data otomatis tersimpan ke server.
Ketika link dibuka di HP Bapak, HP murid, atau HP orang tua, aplikasi langsung mengambil data master terbaru dari server.
Panel Kontrol Sinkronisasi &amp; Cadangan di Dashboard GuruDi bagian atas Dashboard Guru (Drs. PAIYO), kini tersedia panel "DATABASE SERVER &amp; SINKRONISASI HP":
🟢 Status Sinkronisasi (Real-Time): Menampilkan status keterhubungan dan jam sinkronisasi terakhir.
💾 Simpan ke Server: Tombol untuk memastikan data yang baru Bapak ubah langsung dikirim ke server.
🔄 Sinkron Server: Untuk memuat ulang data terbaru dari server jika diperlukan.
📤 Cadangkan JSON &amp; 📥 Pulihkan JSON: Memungkinkan Bapak mengunduh file cadangan data seluruh kelas ke komputer/HP dan memulihkannya kapan saja.
Menu "📲 Bagikan ke HP" (Link Per Kelas &amp; WhatsApp)
Tersedia tombol "Bagikan ke HP" untuk menyalin link utama aplikasi atau link langsung ke kelas tertentu (misal: link langsung membuka Kelas 9A atau 9B).

Cara Kerja  "Kunci HP Saya":
Tombol "Kunci HP Saya" di Layar Murid (Mudah &amp; Cepat):
Pada bagian atas aplikasi di HP murid, terdapat banner pelindung: [🛡️ KUNCI AKUN DI HP INI: Cegah teman mengisikan sholat atas namamu].
Murid cukup menekan tombol [🔒 Kunci HP], lalu memasukkan PIN (bisa menggunakan PIN default 1234 atau PIN 4 angka buatan sendiri).
Setelah dikunci, profil HP tersebut akan bertanda 🔒 AKUN TERKUNCI (AMAN) khusus atas nama murid tersebut.
Perlindungan Otomatis Terhadap Pergantian Nama:
Jika ada teman yang meminjam HP dan mencoba mengganti nama murid ke nama orang lain, aplikasi akan langsung menghadang dengan jendela verifikasi PIN keamanan.
Tanpa memasukkan PIN yang benar, nama murid tidak bisa diubah dan sholat tidak bisa dicatatkan untuk orang lain.
Master PIN Khusus Guru (Pak Drs. PAIYO):
Jika sewaktu-waktu murid lupa PIN-nya, Bapak Drs. PAIYO dapat langsung membuka kunci HP murid manapun dengan memasukkan Master PIN Guru: 1234.
Link Khusus Per-Murid Terkunci Otomatis (dari Dapur Guru):
Pada menu "Bagikan Link Aplikasi ke HP" di Dashboard Guru, Bapak Drs. PAIYO dapat langsung menekan tombol [🔒 Salin Link Kunci] di samping nama murid yang diinginkan.
Saat link tersebut dibuka oleh murid di HP-nya, aplikasi otomatis mengunci HP tersebut atas nama murid yang bersangkutan.
Pembaharuan kedua:
Ringkasan Fitur yang Telah Diimplementasikan:
1. Server Database Sentral (/api/grades &amp; server_data/database.json)
Penyimpanan Berkas JSON Terstruktur (Server Storage Engine):
Berkas penyimpanan utama berlokasi di server_data/database.json.
Menggunakan teknik Atomic Safe-Write (menulis berkas temporary lalu mengganti secara atomik), sehingga file tidak akan rusak meski terjadi lonjakan koneksi bersamaan.
Endpoint sentral GET &amp; POST /api/grades, POST /api/grades/record, GET &amp; POST /api/grades/settings, dan POST /api/grades/reset telah aktif.
2. Sinkronisasi Otomatis Antar Perangkat (Real-Time Auto-Polling)
Sinkronisasi Berkala Cerdas:
Semua HP murid dan laptop guru otomatis melakukan polling ke server secara berkala (default: 12 detik, dapat diatur).
Menggunakan mekanisme Diff Check (modified: false jika data belum berubah), sehingga sangat hemat kuota dan cepat (&lt;10ms).
Ketika murid mencatat sholat dari HP-nya, rekapan di layar guru langsung bertambah secara otomatis.
Otomatis langsung menyinkronkan saat layar HP menyala atau murid kembali membuka tab browser (visibilitychange).
3. Indikator Status Database Sentral
Pada Layar Murid (Header Aplikasi):
Terdapat indikator hijau menyala: 🟢 Database Sentral Terhubung • server_data/database.json.
Murid/Guru dapat menekan indikator tersebut untuk membuka jendela diagnostik lengkap (status koneksi, waktu sinkron terakhir, dan tombol Sinkronkan Sekarang).
Pada Dashboard Guru:
Banner status real-time dengan status Tersambung (Real-Time), jumlah murid &amp; catatan, serta tombol pintas ekspor/impor.
4. Penyimpanan Cadangan Ganda (Dual Backup Architecture)
Cadangan 1: Fitur "Impor Nilai (Kode WA)" &amp; "Ekspor Kode WA":
Tombol [📤 Ekspor Kode WA]: Menghasilkan teks data terenkripsi Base64 ringkas yang langsung dapat disalin atau dikirim ke chat WhatsApp guru/grup sekolah.
Tombol [📥 Impor Kode WA]: Guru cukup menempelkan teks chat WA tersebut ke dalam sistem. Sistem secara otomatis mendeteksi jumlah siswa, catatan sholat, dan menyediakan pilihan:
Gabungkan (Merge): Menambahkan rekaman baru tanpa menimpa data lama (direkomendasikan).
Timpa Seluruhnya (Replace): Mengganti database saat ini dengan data dari Kode WA.
Cadangan 2: Cadangan Lokal Browser (Local Snapshot):
Otomatis menyimpan snapshot cadangan di browser setiap kali ada sinkronisasi baru, lengkap dengan riwayat waktu dan jumlah siswa.
5. Pengaturan Token &amp; Jadwal Terpusat (Tab "Database Sentral")
Menu baru di Dashboard Guru: 🗄️ Database Sentral, memuat kontrol terpusat:
Master Token / PIN Guru: Default 1234 (dapat diubah sesuai kebutuhan).
Nama Sekolah &amp; Tahun Ajaran: SMPN 1 Bantarkawung, 2026/2027, Semester Ganjil.
Interval Auto-Polling: Pilihan kecepatan 8s, 12s, 20s, hingga 60s.
Penyesuaian Jadwal Sholat Terpusat: Offset menit Subuh, Dzuhur, Ashar, Maghrib, Isya (+/- menit) untuk penyesuaian adzan masjid setempat.
6. Tombol "Reset Data" Aman dengan Password
Terdapat di zona perlindungan khusus pada tab Database Sentral:
Opsi 1: Kosongkan Catatan Sholat Saja (Siswa &amp; Rombel tetap aman tersimpan).
Opsi 2: Reset Database Penuh (Untuk mulai tahun ajaran baru dari nol).
Perlindungan Keamanan: Wajib memasukkan Master Token/Password Guru (default: 1234).
Snapshot Otomatis: Server otomatis membuat salinan cadangan di folder server_data/backups/ sesaat sebelum penghapusan dilakukan, sehingga data tidak akan hilang secara tidak sengaja.
