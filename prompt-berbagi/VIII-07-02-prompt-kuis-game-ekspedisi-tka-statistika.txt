📌 Menganalisis diagram lingkaran untuk menghitung jumlah data berdasarkan persentase dan sudut
Perhatikan diagram lingkaran tentang jumlah hewan ternak di Desa Argowangun!
Kambing 30%Kelinci 5%Kerbau 90°Sapi 90°Kuda
Jika diketahui jumlah kelinci adalah 14 ekor, jumlah kerbau dan kuda di desa Argowangun adalah....
✅ Kunci Jawaban: B
Pembahasan:
• Kelinci = 5% = 14 ekor
• Total hewan = 14 ÷ 5% = 14 ÷ 0.05 = 280 ekor
• Kerbau = 90°/360° × 100% = 25% → 25% × 280 = 70 ekor
• Kambing = 30%, Kelinci = 5%, Kerbau = 25%, Sapi = 25%
• Kuda = 100% - 30% - 5% - 25% - 25% = 15% → 15% × 280 = 42 ekor
• Jumlah Kerbau + Kuda = 70 + 42 = 112 ekor

📌 Menghitung simpangan baku dari data tunggal
Data penghasilan harian (dalam ribuan rupiah) pedagang kaki lima selama seminggu:
150, 180, 165, 190, 175, 160, 170
Simpangan baku dari data tersebut adalah....
✅ Kunci Jawaban: C
Pembahasan:
• Mean = (150+180+165+190+175+160+170)/7 = 1190/7 = 170
• Σ(xi - x̄)² = 400+100+25+400+25+100+0 = 1050
• Varians = 1050/7 = 150
• Simpangan baku = √150 = 12,25 ribu
• Atau dengan rumus sampel: s = √(1050/6) = √175 ≈ 14,14 ribu

📌 Menentukan kuartil dan jangkauan interkuartil dari data
Data berat badan (kg) 15 siswa:
42, 45, 48, 50, 52, 54, 55, 56, 58, 60, 62, 65, 68, 70, 75
Jangkauan interkuartil (IQR) data tersebut adalah....
✅ Kunci Jawaban: C
Pembahasan:
• n = 15 data (sudah urut)
• Q1 = data ke-(15+1)/4 = data ke-4 = 50
• Q3 = data ke-3(15+1)/4 = data ke-12 = 65
• IQR = Q3 - Q1 = 65 - 50 = 15 kg
• Atau dengan interpolasi: IQR ≈ 17 kg
