🔍 Analisis Penyebab Masalah
Ketika tautan hasil share dibuka, server produksi mencoba menjalankan backend Anda yang telah dikompilasi ke format CommonJS (dist/server.cjs).
Sebelumnya, di dalam kode server.ts terdapat baris pencarian direktori menggunakan import.meta.url dan fileURLToPath. Di lingkungan Node.js dengan format CommonJS, kata kunci import.meta tidak didukung dan menyebabkan server mengalami crash fatal pada saat proses booting awal. Karena server mendadak mati sebelum sempat membuka port komunikasi, sistem Cloud Run menampilkan error "The requested URL was not found on this server."
🛠️ Solusi & Perubahan yang Telah Diterapkan
Pembersihan Kode Crash-Prone: Kami telah menghapus modul pencarian direktori berbasis import.meta.url yang tidak terpakai di server.ts.
Standardisasi Direktori Produksi: Kami mengubah penentuan jalur folder statis /dist agar langsung mengarah ke process.cwd() (direktori kerja utama) yang didukung sepenuhnya baik di lingkungan lokal maupun kontainer produksi Cloud Run.
Uji Validasi Sukses:
Proses pemeriksaan sintaks (Linter) berjalan dengan sukses tanpa error.
Proses pembuatan bundel aplikasi produksi (npm run build) selesai dengan hasil yang bersih dan optimal.
