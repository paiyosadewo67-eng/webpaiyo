Menyelesaikan SPLDV dengan metode eliminasi dan substitusi untuk menentukan nilai ekspresi aljabar
Jawaban Anda: A. –3
Kunci: C. 1
✗ Salah (0 poin)
Pembahasan:
Dari persamaan: 2a + b = 9 → b = 9 - 2a
Substitusi ke: 3a + 2(9-2a) = 16
3a + 18 - 4a = 16
-a = -2 → a = 2
b = 9 - 2(2) = 9 - 4 = 5
Jadi, 2a - b = 2(2) - 5 = 4 - 5 = -1
Jawaban: B. -1

Menganalisis fungsi linear melalui diagram panah dan menentukan rumus fungsi serta nilai variabel
Jawaban Anda: Lihat pembahasan
✗ Salah (8 poin)
Pembahasan:
* f(8) = 29  8a + b = 29 ... (1)
* f(4) = 13  4a + b = 13 ... (2)

Eliminasi: 4a = 16 → a = 4
Dari (2): 16 + b = 13 → b = -3

• a + b = 4 + (-3) = 1 ≠ -1 → Salah
• f(x) = 4x - 3 → Benar
• f(3x+2) = 4(3x+2) - 3 = 12x + 8 - 3 = 12x + 5 → Benar

Menerapkan SPLDV untuk menyelesaikan masalah kehidupan sehari-hari tentang jumlah dan nilai
Jawaban Anda: B. Rp500.000,00
Kunci: A. Rp494.000,00
✗ Salah (0 poin)
Pembahasan:
Misalkan: m = jumlah mobil, s = jumlah motor
m + s = 172 ... (1) → jumlah kendaraan
4m + 2s = 448 ... (2) → jumlah roda

Dari (1): s = 172 - m
Substitusi ke (2): 4m + 2(172-m) = 448

= 260.000 + 240.000 = Rp494.000,00
